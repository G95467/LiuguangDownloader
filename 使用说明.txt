流光下载器  v1.0.0
极速 · 多线程 · 免费 · 无广告

============================================================
一、启动
============================================================
双击“流光下载器.exe”即可。

如果 Windows 弹出“Windows 已保护你的电脑”，这是未购买商业代码签名的正常提示。
点击“更多信息”，再点“仍要运行”即可。

运行环境：
• Windows 10 / 11 64 位
• Microsoft Edge WebView2 运行时（Windows 10/11 通常已安装）
• .NET 10 Desktop Runtime（当前电脑已安装）

如果换到另一台电脑提示缺少组件：
• .NET 10：https://dotnet.microsoft.com/download/dotnet/10.0
• WebView2：https://developer.microsoft.com/microsoft-edge/webview2/

============================================================
二、开始下载
============================================================
1. 复制一个 HTTP / HTTPS 下载直链。
2. 在主界面的链接框中粘贴，按 Enter。
3. 也可以点击“新建下载”，为本次任务指定文件名、保存位置、
   线程数、Referer、Cookie 或自定义请求头。

可以一次粘贴多条链接，每行一条，程序会自动排入队列。

默认设置：
• 每个任务 16 个连接
• 同时下载 3 个任务
• 保存到 C:\Users\<你的用户名>\Downloads\流光下载

右上角太阳 / 月亮按钮可以切换深色、浅色模式。
设置面板里还可以选择“跟随系统”。

============================================================
三、主要功能
============================================================
• 多线程分段下载：1 ~ 32 个并发连接（默认 16）
• 自动识别服务器是否支持 Range；不支持时自动单线程下载
• 暂停、继续、重试、移除任务
• 断点续传：关闭程序后再打开，可以从上次完成位置继续
• 智能文件名：支持 Content-Disposition、中文文件名、自动避免重名
• 自动跟随 301 / 302 / 303 / 307 / 308 重定向
• Cookie、Referer、自定义请求头、URL 内置账号密码
• 搜索任务、拖动链接到窗口、识别剪贴板链接
• 完成提示音、任务栏下载进度
• 深色 / 浅色 / 跟随系统三种主题
• 所有下载处理都在本机完成，无广告、无统计、无捆绑

“高级”设置中可以允许无效 HTTPS 证书。除非你确认那个网站可信，
否则不要开启。默认保持关闭。

============================================================
四、命令行
============================================================
在命令行中传入一个或多个链接，程序会直接加入队列：

  流光下载器.exe "https://example.com/file.zip"
  流光下载器.exe "https://example.com/a.bin" "https://example.com/b.bin"

同一条命令最多接收 30 个链接。

============================================================
六、文件保存在哪里？
============================================================
默认下载位置：
  C:\Users\<你的用户名>\Downloads\流光下载
可在设置中随时更改。

下载中的文件会带 .lgpart 后缀，下载完成后自动变成正式文件。
暂停或意外关闭时保留的临时文件会在继续下载时复用。
移除未完成任务时，临时文件会被清理。

程序配置和任务记录保存在：
  %LOCALAPPDATA%\LiuguangDownloader
这是独立于本文件夹的用户数据目录，升级、移动程序时不会丢失任务。
下载目录中的文件不会因为这个目录被删除。

============================================================
七、“所有链接”都能下载吗？
============================================================
本程序是 HTTP / HTTPS 直链下载器，适合：
• 普通文件、软件安装包、压缩包
• 图片、音频、视频等 CDN 链接
• 带重定向、签名参数、Content-Disposition 的下载地址

它不解析网页播放器、网盘登录页、BT / 磁力链接、M3U8 / HLS
播放列表，也不能自动完成“登录、点击、验证码”等交互。
遇到这类页面，请先用浏览器或对应工具取得真实的 HTTP 直链，
再把直链粘贴进来。

如果服务器需要登录 Cookie 或防盗链 Referer，可以在“新建下载
→ 自定义请求头”里填写，只对那一次任务生效。

部分服务器会限制单个 IP 的连接数或单线程速度，实际速度取决于
服务器。程序会自动重试；服务器拒绝 Range 时只能从头下载。

============================================================
八、常见问题
============================================================
问：为什么暂停后进度会稍微倒退？
答：正在传输但还没完成的分段会在暂停时丢弃，只保留已检查点
    完成的分段；继续下载会从最后一个完整分段开始，以确保文件
    不会损坏。小分段策略已经把损失控制在很小范围内。

问：为什么下载速度没有跑满带宽？
答：1) 服务器限速；2) 服务器限制并发连接；3) 服务器不支持分段；
    4) 本地网络或磁盘瓶颈。可以在设置中提高连接数，或更换下载源。

问：链接返回 403 / 404？
答：链接可能已过期、需要登录、需要 Referer，或者服务器拒绝
    非浏览器请求。尝试在“新建下载”的请求头里补上 Referer / Cookie。

问：杀毒软件报毒怎么办？
答：这是未签名的小工具常见的误报。你可以先查文件属性，确认是
    本文件夹中的程序；如果不放心，请不要运行。

问：任务列表在重开程序后变成“已暂停”？
答：这是保护机制。程序不会在后台悄悄重新开始下载；点击任务右侧的
    “继续下载”才会恢复，断点记录会保留。
